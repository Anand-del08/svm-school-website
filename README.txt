# Sanskar Vidhya Mandir School Website

A responsive bilingual (English/Hindi) school website starter built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content and page sections
- `style.css` — responsive maroon, cream and gold design
- `script.js` — language switch and mobile navigation
- `images/` — place your own school photos and logo here

## Run in VS Code
1. Download and extract `SVM-School-Website.zip`.
2. Open VS Code.
3. Select **File → Open Folder...** and choose the extracted `SVM-School-Website` folder.
4. Open `index.html`.
5. If you have the **Live Server** extension, right-click `index.html` and select **Open with Live Server**.
6. Otherwise, double-click `index.html` in File Explorer to open it in your browser.

## Before publishing
- Replace sample stock photos with approved real photos of your school.
- Add the school's real logo and confirm the correct spelling of the school name.
- Confirm classes, curriculum, facilities, address, public phone number and official email.
- The admission enquiry form is configured to email submissions to sanskarvidyamandirgunawata@gmail.com using FormSubmit. On first use, check the school inbox for a FormSubmit activation email and click its confirmation link. Until the form is activated, submissions may not arrive. FormSubmit is a third-party service; review its privacy terms before collecting personal information. Test the form after publishing the site online.
- The page uses Google Fonts and remote sample photos, so those assets require an internet connection.
