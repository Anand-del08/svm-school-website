SANSKAR VIDHYA MANDIR SECONDARY SCHOOL WEBSITE

This version uses the real photographs supplied in this chat. Sample/stock photos have not been included.

Files:
- index.html: website page
- style.css: design and responsive layout
- script.js: interactive behavior
- images/: selected school photographs

To preview: open index.html in a browser. Keep the images folder beside index.html.
To publish: upload the contents of this folder to your web hosting, preserving the folder structure.

Photo selection: study-time banner, student Holi celebration, school bus, yoga/exercise, student health check-up, outdoor student gathering, and cultural dress-up. Some additional uploaded event photos were omitted because their banners visibly identify a different school.
